# 📂 Database Overview

This folder contains the structure and analysis of a university database.

## 📌 Contents

- Tables: Definition of database structure (students, professors, courses, enrollments)
- Queries: SQL scripts used for analysis
- Analysis: Business-oriented queries to extract insights

## 🎯 Purpose
The goal of this database is to simulate a real academic environment and analyze:

- Student distribution  
- Course demand  
- Teaching assignments  
- Resource utilization  

## 💡 Approach
Instead of only focusing on database structure, this project emphasizes how SQL can be used to extract meaningful insights and support decision-making.
